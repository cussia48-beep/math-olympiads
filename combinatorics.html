Learn permutations and combinations, the pigeonhole principle, inclusion-exclusion, recursion, graph models and invariants.

If n+1 objects occupy n boxes, at least one box contains ≥2 objects.

How to attack counting problems

  1. Decide whether order matters.
  2. Count the same set in two different ways.
  3. Break a complicated object into cases.
  4. Search for a forced repetition or invariant.
  5. Test a small version to reveal a pattern.

Think in objects and constraints

Many hard counting problems become easier when you stop counting arrangements directly and instead model the restrictions as a graph or a sequence of choices.
